# 公开演示资料来源

本目录中的人工智能基础 Markdown、TXT 与 PDF 为本项目自制的教学示例，用于测试上传和学习流程。文本来自 `backend/data/demo.mjs` 及 `scripts/e2e.mjs` 中的自制概念介绍，不来自学生或教师的原始课件。

允许公开的 PDF 仅有 `AI-基础示例.pdf`。真实课程 PDF、个人笔记和未经确认的资料不要放入此目录；本机测试资料放到项目以外或被忽略的 `private-materials/`。

截图全部使用本目录的自制资料和内置示例课程。测试中的机构、讲师、邮箱为虚构占位，域名使用保留的 `example.invalid`。
