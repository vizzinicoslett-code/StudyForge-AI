# 公开资料与隐私审查

范围：Git 实际会提交的源码、测试、文档、Demo 文件、截图和部署配置。私有本机产物不在此范围。

## 公开资料来源

- 唯一允许公开的 PDF 为 demo-materials/AI-基础示例.pdf，内容为项目自制的 AI 基础介绍。
- TXT / Markdown 与 backend/data/demo.mjs 同源，未使用教师课件或学生笔记。
- 截图由独立 headless 浏览器会话使用自制 Demo 生成，不读取使用者原有浏览器记录。
- 重点提炼截图按用户要求仅保留在本地，不进入 GitHub 或公开展示包；公开截图共九张。
- 测试中的讲师、机构为虚构占位，邮箱和 URL 使用 example.invalid 保留域名。

## 排除内容

.env、node_modules、frontend/dist、本机日志、缓存、artifacts、private-materials、uploads 不进入 GitHub。真实课程 PDF、本机私有 PDF 的摘录、检查结果和绝对路径不进入公共展示包。本机原始文件保持不动。

## 可复现检查

执行 `node scripts/privacy-check.mjs`，读取 Git 候选文件集合，检查令牌、非虚构邮箱、本机绝对路径、学号手机号与未经确认的 PDF；检查 PNG 文本/EXIF 元数据。清单和散列存放在被忽略的 artifacts/。

自动扫描不代替资料来源判断。图像内容由自制 Demo 生成流程及视觉检查确认。新增示例、截图或文档后应重新检查来源，避免将私人课程素材混入公开提交。
