## 已知限制

1. Mock 重点规则面向中文：纯英文 AI-基础示例.pdf 上传、解析正常，提炼重点返回 HTTP 400 / SUMMARY_INSUFFICIENT_CONTENT。同一文本的本地结果一致。中文 PDF 的完整学习流程通过；未为英文支持增加新功能。
2. 本项目部署于 Render Free。服务长时间无人访问后可能进入休眠，首次打开可能需要等待约 1 分钟，服务唤醒后即可正常使用。
3. 本次未主动让服务休眠或独立计时冷启动；约一分钟依据 Render 平台说明。休眠或重启后服务器内存资料和测验会失效，可恢复资料并重新出题。
4. 扫描或加密 PDF 不含 OCR 支持；TXT/Markdown 使用 UTF-8。免费实例受流量、构建分钟和实例时长额度限制。
5. Mock 是规则演示，不代表真实大模型理解；无在线模型、付费 API 或 API Key。

免费平台说明：[Render Free](https://render.com/docs/free)。
