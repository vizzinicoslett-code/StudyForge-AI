## 背景与目标

大学生复习常常面对很多课程资料，却不确定先学什么、哪些概念没理解，以及看完以后是否真正掌握。本项目将资料阅读、知识整理与自我测试串成一条学习路径，制作了一个可通过 Render 公网访问、也可在本机运行的 Web 学习助手。

目标是让学生把 PDF、TXT 或 Markdown 课程资料转化为可阅读、可练习、可反馈的学习内容。产品不做账号、支付和大型后台，优先保证流程完整、操作清楚、结果可核对和演示可复现。

## 主要功能与使用场景

| 功能 | 最终行为 |
|---|---|
| 首页 | 上传资料、继续最近一次学习、体验内置示例课 |
| 资料解析 | 显示名称、类型、大小、解析状态；损坏 PDF 和编码错误有提示 |
| 重点提炼 | 课程主线、5～10 个知识点、★ 重要程度、必须掌握和可以略读 |
| 复习提纲 | 分部分组织知识，标记理解、记忆、计算、易错 |
| 知识问答 | 检索资料片段，优先依据资料回答并显示来源；资料外补充明确标注 |
| 自动测试 | 5 或 10 题，只包含单选和判断，后端校验输出 |
| 成绩与建议 | 统计正确/错误数、得分、逐题解析，针对本次错题安排复习 |

适用于课前预习、章节复习、考前自测，以及课堂展示 AI 技术应用。不是正式考试评分系统，生成的重点也不是教师划定的考试范围。

## 创新点

1. 将常见 AI 问答变为完整学习闭环，让学生从阅读一直走到自测与反馈。
2. 使用课程资料增强回答，显示可展开的原文片段，方便学生检查依据。
3. 给提纲标记学习方法，让学生知道内容适合理解、记忆、计算还是注意易错点。
4. 将真实 AI 与 Mock 演示明确区分：课堂没有 Key 时也可展示交互，配置服务后才调用真实模型。
5. 模型负责生成，程序负责检查格式与评分，体现 AI 与传统程序的协作。

## 技术架构

前端使用 React、TypeScript 和 Vite；后端使用 Node.js、Express、pdf-parse 和 Zod。AI 接口采用 OpenAI-compatible Chat Completions 协议，从 `.env` 读取密钥、服务地址和模型标识。

后端先解析课程文本并切分为有编号的片段，问答时以中文双字词和英文单词检索相关片段，将片段加入提示词。五类提示词独立存放，统一采用「系统角色 + 任务说明 + 课程上下文 + 输出 Schema」。模型返回 JSON 后，程序校验字段、类型、选项、答案范围和数量，合格后再展示。测验答案不随未提交的题目返回前端，评分由后端完成。

## 最终效果与边界

已完成可运行产品、内置课程、三类示例文件、9 张公开展示截图及全部课程材料。代码包含后台和无界面浏览器验收脚本。实际测试证据见 `../测试报告.md`，截图见项目 `screenshots/`。

V1 不含 OCR、向量数据库、长期用户画像和多用户服务。Mock 为基于资料的规则演示，不代表真实大模型推理。真实接口协议已通过本机 HTTP 测试服务验证；远程模型实测与质量评估仍需使用者填写真实 API 配置后完成。
