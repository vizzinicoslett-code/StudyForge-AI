# 当前公开展示版本说明

本课程展示版本使用 Mock / 本地规则处理，不调用在线 AI 服务、不需要 API Key。文中模型接口与 Prompt 部分属于原设计的技术说明；当前录屏和答辩应按 Mock 分支介绍。公开版本不填写真实成员信息，不使用未获公开许可的课件。

# 详细操作步骤

## 实际使用的工具

- Codex：理解需求，编写代码与提示词，执行命令行测试，整理材料。
- PowerShell：查看目录与开发环境，安装依赖、执行构建和测试。
- Node.js v24.20.0 / npm：运行后端、前端构建与测试脚本。
- React、TypeScript、Vite：制作浏览器界面并检查类型。
- Express、pdf-parse、Zod：处理上传、提取 PDF 文本和检查模型输出。
- Playwright 与现有 Microsoft Edge：以 headless 模式验收，不操作可见窗口。
- OpenAI-compatible HTTP 测试服务：验证模型请求与响应协议。未使用学生个人的真实 API Key。

VS Code 不是本次自动开发中实际操作的工具；小组后续可以用它阅读和修改项目。项目没有使用多个代理代替真实组员，也没有编造成员身份。

## 一步一步完成项目

### 1. 确定产品主题

阅读课程要求后，将主题确定为大学生课程学习助手。核心问题是“有资料但复习没方向”，因此选择把资料转化为重点、提纲、题目和学习建议。

### 2. 设计需求

限定 V1 只做一份课程资料的一次学习流程。列出上传格式、五个 AI 功能、无 API 时的演示模式，以及需要交付的课程材料。没有加入登录、社交或支付等无关功能。

### 3. 检查环境并建立项目

检查当前目录，确认目录为空；验证 Node.js、npm 和 Python 可用。创建 StudyForge-AI，划分前端、后端、提示词、测试、文档和截图目录。安装 React、Express 等依赖并生成 package-lock.json，保证后续可按相同依赖版本安装。

### 4. 设计页面

首页用大标题、上传卡片、示例课和最近记录说明使用方式。工作台左侧放课程与导航，中间显示原文和生成内容，右侧放学习操作。使用浅色背景和深绿按钮，减少动画与无关统计图。根据截图检查结果调整文字字号，让正文更容易阅读。

### 5. 编写 AI 提示词

分别为总结、提纲、问答、出题和复习建议编写独立文本文件。系统提示词要求资料只作为数据、优先使用资料、不编造来源，并返回 JSON。每个任务附带具体输出格式，方便程序检查和老师阅读。

### 6. 接入模型协议与演示模式

实现统一 Provider，从环境变量读取服务配置。真实模式发送 Chat Completions HTTP 请求；没有 Key 时使用规则化 Mock。界面展示模式标记，真实请求失败时显示错误，不自动伪装成成功。用本机测试服务验证了认证、模型名称、JSON 请求参数与响应处理。

### 7. 解析资料与实现资料增强

PDF 交给 pdf-parse 提取文本，TXT/Markdown 按 UTF-8 解码。对文件大小、文本长度、损坏格式和空内容做检查。将文本按约 900 字切分、重叠 120 字，赋予 S 编号；问题用中文双字词及英文单词匹配相关片段，作为模型上下文。前端可展开片段核对来源。

### 8. 完成学习功能

先实现重点与提纲，再实现问答、5/10 题生成和答案选择。模型 JSON 先经过 Zod 和题目语义校验，未通过就提示重新生成。用户提交后，服务器比较答案、计算成绩并给出逐题解析。复习建议使用服务器保存的本次错题，而不是相信客户端传来的分数。

### 9. 测试与修复

先在后台测试文件解析、Mock 流程、接口模式、异常情况和评分。实际发现了中文问题匹配不精确的问题，修复为双字词匹配与相关度门槛。安装、构建和本机回环请求受到 Windows 沙箱限制时，在已授权范围内改用正常权限运行。随后使用无界面 Edge 检查实际页面交互，修正按钮的无障碍名称并验证移动布局。

### 10. 完成产品与提交材料

构建正式前端，执行无界面学习闭环并保存截图。将实际提示词和输出 Schema 导出为课程文档，补充 AI 原理、分工模板、录屏脚本和答辩稿。将源码、锁文件、正式构建、示例文件、测试报告和课程材料整理为 submission 目录及带占位姓名的压缩包。

## 同学如何复现

解压提交包，进入 StudyForge-AI，执行 `npm ci`、`npm run build`、`npm start`，浏览器打开本机 3001 端口。先用示例课程体验全部流程，再上传自己的章节资料。如需真实 AI，在 `.env` 中填写 Key、地址和模型，重启后确认页面显示「真实 AI 模式」。

本记录描述实际开发操作。正式提交前，应补充小组成员亲自检查、修改、真实模型试用和录屏的过程；不能把 AI 自动完成的工作全部声称为成员手工完成。
