# 当前公开展示版本说明

本课程展示版本使用 Mock / 本地规则处理，不调用在线 AI 服务、不需要 API Key。文中模型接口与 Prompt 部分属于原设计的技术说明；当前录屏和答辩应按 Mock 分支介绍。公开版本不填写真实成员信息，不使用未获公开许可的课件。

# 2～3 分钟录屏脚本

建议长度约 2 分 45 秒。使用 1440×900 或 1920×1080，浏览器缩放 100%，提前启动服务。关闭无关页面与通知，避免录到 API Key。可以用系统录屏工具人工录制，本项目没有自动生成视频。

先决定录制模式：未配置 Key 就介绍为「Mock 交互演示」；真实模式须先配置并核验五项功能，不能把规则演示称为真实模型输出。

| 时间 | 画面与操作 | 建议旁白 |
|---|---|---|
| 00:00–00:15 | 首页，展示名称和模式标记 | “这是 StudyForge AI，目标是把大学课程资料变成一个可复习、可测试的学习流程。本次使用的是[Mock 演示 / 真实 AI]模式。” |
| 00:15–00:35 | 选择 demo-materials/人工智能基础.md，点击开始学习 | “支持 PDF、TXT 和 Markdown。上传后会提取文本并显示解析状态；扫描 PDF 需要先 OCR。” |
| 00:35–00:55 | 点击提炼重点，滚动知识卡片 | “这里先说明资料主线，再列核心知识点，用星级建议学习优先级，并区分必须掌握和可以略读。” |
| 00:55–01:10 | 生成提纲，指出学习类型标签 | “提纲把知识按逻辑组织，并标记理解、记忆、计算与易错，告诉我们怎么复习。” |
| 01:10–01:30 | 问“什么是过拟合？”，展开来源 | “问答会先检索课程片段。我们可以打开原文检查依据；资料不足时会明确提示补充解释。” |

## 录制前彩排

先完整操作一次，确认无错误提示；真实模型可能需要等待，把生成过程适度剪辑，保持总时长。提前阅读 5 道题，安排一题答错，让复习建议有具体内容。最后保存视频为 `组号-StudyForgeAI-成员姓名-演示.mp4`，自行放到最终提交文件夹，并检查教师要求的视频格式和大小。
