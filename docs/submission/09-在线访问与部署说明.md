## 为什么不使用 GitHub Pages

当前 Express 负责上传、PDF 文本解析、Mock 生成、答案保管、评分及复习建议。GitHub Pages 不运行这个 Node 后端。选择同源 Node 托管保留既有功能，避免静态化重构。

## Render 设置

- 仓库根目录 render.yaml，一个 type:web、runtime:node、plan:free 服务。
- 构建 npm ci --include=dev && npm run build，启动 npm start。
- NODE_ENV=production、HOST=0.0.0.0、AI_MODE=mock、NODE_VERSION=24.20.0。
- PORT 由平台提供，健康检查 /api/health。
- 没有数据库、永久磁盘、AI Key 或收费附加服务。

Render 登录后 New → Blueprint → 选择仓库 → 确认 Free 计划 → Deploy。也可通过 New → Web Service 填写同样设置。不要选择付费实例；账号若要求付款或升级，请先停止，不自动接受。

## 免费实例限制

连续 15 分钟无流量会休眠，下一次访问唤醒通常约一分钟。重启/休眠后服务器内存资料和测验不保留，可重新体验示例课程或从浏览器最近记录恢复资料。免费额度受实例小时数、带宽和构建分钟限制，详见 [官方说明](https://render.com/docs/free)。
