## 部署状态与验收

Render 控制台状态 Live、实例 Free 由使用者提供；公网服务实际完成 HTTP 与 headless 浏览器验收。测试环境是 Windows 客户端访问 Render 公网服务，全程未启动 localhost 替代测试。

详细公网 API 29 项、公网浏览器 28 项，共 57 项通过，0 项失败。另有 13 项初步公网检查通过，不重复计入总数。

英文 PDF 重点返回 HTTP 400 是既有中文规则限制，与本地一致；中文 PDF 的上传、解析、重点、提纲、问答和测验通过。未修复或修改任何产品功能、UI 或部署代码。

## 现有部署配置

仓库根目录 render.yaml：一个 Node Free Web Service；构建 npm ci --include=dev && npm run build，启动 npm start。NODE_ENV=production、HOST=0.0.0.0、AI_MODE=mock；平台提供 PORT，健康检查 /api/health。前端使用同源 /api，无数据库、永久磁盘或 AI Key。

本地：进入项目，首次 npm ci --include=dev 和 npm run build，然后 npm start，访问 http://127.0.0.1:3001。

## 资料与已知限制

仅测试自制 Demo，未上传原始私人课程 PDF，也未修改本机原文件。上传在内存解析，不依赖永久磁盘；服务重启或休眠后测验可能失效，请重新生成。扫描或加密 PDF 不在支持范围。免费额度和休眠规则见 [Render 官方说明](https://render.com/docs/free)。
