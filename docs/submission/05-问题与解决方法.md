# 当前公开展示版本说明

本课程展示版本使用 Mock / 本地规则处理，不调用在线 AI 服务、不需要 API Key。文中模型接口与 Prompt 部分属于原设计的技术说明；当前录屏和答辩应按 Mock 分支介绍。公开版本不填写真实成员信息，不使用未获公开许可的课件。

# 实际问题与解决方法

这里只记录实际遇到或测试中主动复现的问题。没有把真实远程模型未发生的故障写成开发经历。

| 问题 | 实际原因 / 复现方法 | 解决方法 | 最终结果 |
|---|---|---|---|
| npm 下载依赖失败 | 沙箱内访问 registry.npmjs.org 时发生 ENOTFOUND | 在项目授权范围内用允许联网的执行方式安装 | 依赖安装成功；npm 安装审计报告为 0 个漏洞 |
| Vite 构建报 EPERM | Windows 沙箱限制文件 realpath 解析 | 在正常项目文件权限下运行构建 | TypeScript 与生产构建通过 |
| API 测试连接失败 | 沙箱阻止对 127.0.0.1 随机端口的请求，错误为 EACCES | 在正常回环网络权限下运行后台测试 | 测试可执行，并验证了实际 HTTP 链路 |
| 中文问答选错段落 | Mock 最初把整句问题作为一个关键词，导致“什么是过拟合”没匹配过拟合标题 | 使用中文双字词匹配，标题增加权重，检索设置命中数量与相关度门槛 | 问答回归测试通过，答案包含过拟合内容 |
| 无界面验收找不到按钮 | 按钮含标题和副标题，可访问名称与脚本期望不一致 | 给操作按钮添加明确 aria-label | 按钮更易被辅助技术识别，浏览器流程继续验收 |
| PDF 无法提取 / 损坏 | 测试使用伪 PDF、损坏文件和无文本 PDF 主动复现 | 检查 PDF 文件头；捕获解析异常；检查最小文本长度；提示 OCR 或重新导出 | 所有对应错误测试通过，可读 PDF 正常解析 |
| 文本编码不正确 | 测试上传非法 UTF-8 字节 | 严格 UTF-8 解码，不猜测编码，提示另存为 UTF-8 | 错误编码不会当成有效课程文本 |
| 中文上传文件名兼容 | multipart 的文件名可能按 Latin-1 解码 | 对可无损还原的 UTF-8 文件名进行恢复，并测试中文名称 | 中文文件名上传测试通过 |
| 模型输出不符合 JSON / Schema | 用本机兼容服务返回无效 JSON、缺字段和错误引用主动复现 | 后端解析并检查所有输出，题目增加语义检查，拒绝无效结果 | 相应接口返回明确 502 错误，坏数据不进入页面 |
| API 拒绝、限流和超时 | 测试服务主动返回 401、429、500，另模拟超时与不可连接地址 | 分别提供可理解错误提示，超时终止请求，不回显上游敏感内容 | 所有异常路径通过，不静默切换到 Mock |
| 首次压缩未生成 ZIP | Windows 命令子进程的压缩调用结束后，找不到预期输出文件 | 改用 fflate 在 Node 中直接生成 UTF-8 文件名的跨平台 ZIP，并核验文件清单 | 提交 ZIP 已生成，进一步执行完整性检查 |
| 展示正文偏小 | 检查第一版无界面截图发现卡片正文较密 | 提高正文、题目与原文的字号和对比度 | 生成最终截图前完成排版调整 |
